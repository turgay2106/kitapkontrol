# Katkıda Bulunma

Katkılarınızı memnuniyetle karşılıyoruz. Küçük ve odaklı değişiklikler tercih edilir.

1. Önce mevcut issue'ları arayın; büyük değişikliklerde işe başlamadan bir issue açın.
2. Depoyu fork edin ve açıklayıcı bir branch oluşturun.
3. İlgili testleri ekleyin veya güncelleyin.
4. `python -m pip install -e ".[dev]"` ve `pytest` komutlarını çalıştırın.
5. Pull request açıklamasında **What / Why / How / Tests** başlıklarını kullanın.

## Katkı alanları

- EPUB 2/3 yapısal kontrolleri
- Hata mesajlarının açıklığı ve Türkçe/İngilizce çeviriler
- Test dosyaları ve örnek EPUB üretimi
- Dokümantasyon ve kullanım örnekleri

Lütfen gerçek bir problemi çözen değişiklik gönderin. Sırf katkı sayısını artırmak için anlamsız değişiklik göndermeyin.
